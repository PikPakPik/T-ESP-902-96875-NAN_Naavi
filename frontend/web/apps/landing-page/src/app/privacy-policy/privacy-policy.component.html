Politique de Confidentialité

1. Introduction

Naavi ("nous", "notre", "nos") s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment nous collectons, utilisons, partageons et protégeons vos informations personnelles lorsque vous utilisez notre application mobile et nos services.

Cette politique s'applique à l'utilisation de notre application mobile Naavi et de notre site web accessible à l'adresse https://naavi-trails.fr/.

En utilisant Naavi, vous acceptez les pratiques décrites dans cette politique. Si vous n'acceptez pas cette politique, veuillez ne pas utiliser nos services.

2. Informations que nous collectons

Naavi est conçue pour fonctionner sans nécessiter de création de compte ou de connexion. Nous collectons un minimum d'informations pour fournir nos services.

2.1. Données de géolocalisation (facultatives)

La seule donnée personnelle que nous collectons est votre position géographique, et uniquement si vous choisissez de l'autoriser :

  • Position GPS : coordonnées géographiques (latitude, longitude) lorsque vous activez la géolocalisation dans l'application
  • Cette donnée est entièrement facultative - vous pouvez utiliser l'application sans partager votre localisation
  • Vous pouvez activer ou désactiver la géolocalisation à tout moment via les paramètres de votre appareil

2.2. Données techniques automatiques

Certaines données techniques peuvent être collectées automatiquement pour le fonctionnement de l'application :

  • Adresse IP : collectée automatiquement lors de l'utilisation de l'application (nécessaire pour la communication avec nos serveurs)
  • Données techniques de base : type d'appareil, système d'exploitation, version de l'application (pour assurer la compatibilité)

Important : Nous ne collectons pas de nom d'utilisateur, d'adresse e-mail, de mot de passe, ni aucune autre information permettant de vous identifier personnellement.

3. Comment nous utilisons vos informations

Nous utilisons vos informations uniquement pour :

  • Affichage de votre position sur la carte : votre position GPS (si autorisée) est utilisée pour vous localiser sur la carte et améliorer votre expérience de navigation
  • Fonctionnement technique : les données techniques (adresse IP, type d'appareil) sont nécessaires pour que l'application fonctionne correctement

Nous n'utilisons pas vos données pour :

  • Créer un profil utilisateur ou vous identifier
  • Vous envoyer des communications marketing
  • Partager vos données avec des tiers à des fins publicitaires
  • Suivre votre comportement en dehors de l'application

4. Partage de vos informations

Nous ne vendons jamais vos données personnelles.

4.1. Prestataires de services tiers

Nous utilisons le service Mapbox pour fournir les cartes et les fonctionnalités de géolocalisation. Lorsque vous autorisez la géolocalisation dans l'application, votre position GPS est transmise à Mapbox pour :

  • Afficher votre position sur la carte
  • Fournir les services de cartographie et de navigation

Mapbox est soumis à sa propre politique de confidentialité. Nous vous encourageons à consulter la politique de confidentialité de Mapbox pour comprendre comment ils traitent vos données.

4.2. Autres cas de partage

Nous pouvons partager vos informations uniquement dans les cas suivants :

  • Autorités légales : si requis par la loi ou une ordonnance judiciaire, ou pour protéger la sécurité publique
  • Protection de nos droits : pour protéger nos droits, notre propriété ou notre sécurité, ou celle de nos utilisateurs

5. Vos droits

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants concernant vos données personnelles :

  • Droit d'accès : vous pouvez demander une copie des données que nous détenons vous concernant
  • Droit à l'effacement : vous pouvez demander la suppression de vos données
  • Droit d'opposition : vous pouvez vous opposer au traitement de vos données
  • Droit de retirer votre consentement : vous pouvez retirer votre consentement à la géolocalisation à tout moment en désactivant cette fonctionnalité dans les paramètres de votre appareil

Contrôle immédiat : Comme nous ne collectons que votre position GPS (facultative), vous avez un contrôle total sur vos données. Vous pouvez simplement désactiver la géolocalisation dans les paramètres de votre appareil pour cesser tout partage de votre position.

Pour exercer vos autres droits ou pour toute question, contactez-nous à l'adresse : privacy@naavi-trails.fr

6. Sécurité des données

Nous mettons en œuvre des mesures de sécurité techniques et organisationnelles appropriées pour protéger vos données :

  • Chiffrement : les données sont transmises via des connexions sécurisées (HTTPS)
  • Minimisation des données : nous ne collectons que le strict nécessaire pour le fonctionnement de l'application
  • Pas de stockage persistant : nous ne conservons pas de base de données d'utilisateurs ou de positions GPS

Cependant, aucune méthode de transmission sur Internet n'est 100% sécurisée. Nous ne pouvons garantir une sécurité absolue.

Note importante : Comme nous ne collectons pas de données d'identification personnelle et que la géolocalisation est facultative, les risques liés à la collecte de données sont minimisés.

7. Conservation des données

Nous ne conservons pas vos données de géolocalisation.

Votre position GPS est transmise en temps réel à Mapbox pour l'affichage sur la carte, mais nous ne stockons pas ces données sur nos serveurs. Les données techniques (adresse IP) peuvent être conservées temporairement dans les logs de nos serveurs pour des raisons techniques et de sécurité, conformément aux pratiques standards de l'industrie.

Pas de compte, pas de données persistantes : Comme l'application ne nécessite pas de création de compte, il n'y a pas de données personnelles associées à un profil utilisateur à conserver ou supprimer.

8. Données de géolocalisation

La géolocalisation est entièrement facultative dans Naavi. Vous pouvez utiliser l'application sans partager votre position.

8.1. Quand votre position est collectée

Votre position GPS n'est collectée et transmise à Mapbox que si :

  • Vous avez explicitement autorisé l'accès à la géolocalisation dans les paramètres de votre appareil
  • L'application est active et utilise la fonctionnalité de géolocalisation

8.2. Contrôle de votre géolocalisation

Vous avez un contrôle total sur votre géolocalisation :

  • Vous pouvez activer ou désactiver la géolocalisation à tout moment via les paramètres de votre appareil
  • Vous pouvez refuser l'accès à la géolocalisation lors de la première utilisation de l'application
  • Désactiver la géolocalisation n'empêche pas l'utilisation de l'application, mais certaines fonctionnalités (comme l'affichage de votre position sur la carte) ne seront pas disponibles

8.3. Partage avec Mapbox

Lorsque vous autorisez la géolocalisation, votre position est transmise à Mapbox pour l'affichage sur la carte. Cette transmission est nécessaire pour le fonctionnement de la fonctionnalité de géolocalisation. Consultez la politique de confidentialité de Mapbox pour plus d'informations sur leur traitement de vos données.

9. Modifications de cette politique

Nous pouvons modifier cette politique de confidentialité occasionnellement, notamment si nous ajoutons de nouvelles fonctionnalités à l'application. La date de dernière mise à jour est indiquée en haut de cette page.

Nous vous encourageons à consulter régulièrement cette page pour prendre connaissance des éventuelles modifications.

10. Contact

Pour toute question concernant cette politique de confidentialité ou vos données personnelles, contactez-nous :

  • Site web : https://naavi-trails.fr/
  • E-mail : privacy@naavi-trails.fr
  • Responsable de la protection des données (DPO) : dpo@naavi-trails.fr

11. Juridiction applicable

Cette politique de confidentialité est régie par le droit français et européen. Tout litige relatif à cette politique sera soumis à la juridiction des tribunaux français.
